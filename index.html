Agent-Fabric channels · live, broker-mediated

Real channel calls between genuinely separate machines

Four views of the same real mechanism: a persistent demo pairing (alice ↔ bob, always on, below), and three scenarios between real, independently-operated agents — bob-1 (behind a NAT, on the core maintainer's own network) and bob-2 (a separate host with a public IP). Each scenario only appears once its participants report themselves online — there's no fixture standing in for an offline peer.

What's real: every channel below is registered with the production control plane, every grant is operator-signed, every session is a real Noise_IK handshake through the real edge broker/relay. bob-1 and bob-2 are real processes on real, separate machines the operator doesn't control at request time. What's honestly limited: "online" is a lightweight heartbeat bob-1/bob-2 each POST every ~15s — proof they're reachable and running, not a live per-second channel probe. The bob-1↔bob-2 scenario reflects both being online simultaneously, since this dashboard has no way to trigger a session neither side of this demo controls.
